# Git and GitHub Notes

## What is Git?

Git is a version control system.

It records the changes made to a project and allows developers to return to earlier versions.

A Git commit acts like a save point.

---

## Why do we use Git?

Git helps us:

- track changes
- restore previous versions
- work with other developers
- create separate branches
- maintain project history
- experiment safely

---

## What is GitHub?

GitHub is an online platform used to store Git repositories.

Git works on the local computer.

GitHub stores the repository online.

---

## Git and GitHub are different

| Git | GitHub |
|---|---|
| Installed on the computer | Online service |
| Tracks project versions | Stores repositories online |
| Works locally | Supports collaboration |
| Uses commands | Provides a website interface |
